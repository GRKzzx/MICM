# MICM

Experimental materials for the study "When Harmless Words Harm: A New Threat to LLM Safety via Conceptual Triggers".

## Contents

- **Evaluation prompts** — the IAS scoring prompts for all tested ideological orientations
- **Attack prompt template** — the fixed prompt template used by the attack
- **CET pool** — the candidate pool of 238 concept-embedded triggers
- **Incident dataset** — the 500 political incidents used in all experiments
- **Baseline configurations** — prompts, settings, and stopping rules of the four baseline attacks
- **Evaluation code** — the model-judged IAS scoring pipeline
